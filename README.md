# ドラゴンバトルロイヤル（仮）

小学2年生の息子が構想したドラゴン討伐ゲーム。

## あそびかた

1. **冒険する** ボタンで草原・森・岩場・川岸を冒険
2. ふつうドラゴンに出会ったら バトル → 経験値・お金ゲット
3. 何回か倒すと「狭い道」が出現 → 進むとボスドラゴン
4. 狭い道では「落とし穴」に落ちることがある
   - 落とし穴の中には これまで倒した敵の名前が刻まれている
   - 梯子を探して 元の道へ戻る
5. ボスを倒すと たくさんのお金と特別なアイテムをゲット
6. **お店** で アイテム / 食料 / 服 / ペット を購入
7. ペットを買うと バトルで一緒に戦ってくれる

## ファイル構成

```
dragon-battle/
├── index.html   ← メインHTML（画面構造）
├── style.css    ← スタイル
├── data.js      ← ドラゴン・ショップ商品データ
└── game.js      ← ゲームロジック
```
